# Xstream API

A simple Node.js API for the Xstream Football Live Streaming Platform.

## API Endpoints

- `GET /api/` - Main API endpoint
- `GET /api/hello` - Hello endpoint
- `GET /api/test` - Test endpoint

## Deployment

This is deployed on Vercel as a serverless API.

## Database

Connected to Neon PostgreSQL database.
